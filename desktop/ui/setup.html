Where is FaceTimeOS running?

This window is the app itself — it just needs the address of your deployment. Anything like https://facetimeos.vercel.app, or http://localhost:3000 while you are developing.

Google sign-in (optional)

Only needed if you want the Google button to work inside this window. Create an OAuth client of type Desktop app in Google Cloud and paste it here — Google refuses sign-in inside app windows, so the shell opens your real browser and passes the result back. See DESKTOP.md for the five steps.
